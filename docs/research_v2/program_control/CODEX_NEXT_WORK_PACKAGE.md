## Implementable contract decisions

1. Immutable BlockRef/AssetId with strict integer/hex checks. No Python bool-as-int, floats or implicit scalar coercions; chain positive, block/timestamp nonnegative, bytes32/address lengths exact. Address representation canonical lower-case, without claiming checksum proves provenance. Token decimals0…255; native uint quantities0…2^256−1; signed deltas have explicit field/domain, not arbitrary unsigned coercion. Bind units to asset identity, not symbol. Do not enforce that every V2 block is one of the three historical samples; validate fixture selection separately.
2. Tagged Value AVAILABLE/MISSING/UNSUPPORTED/QUARANTINED; AVAILABLE(0) has source/context, missing never becomes0. Nonempty reason and refs for unavailable cases; no ordinary `None` that callers could interpret as available. Result OK/BLOCKED/REJECTED carries reason/affected refs; internal Python/programming errors remain errors, not false economic outcomes. Deep immutability: nested lists/maps cannot mutate a hashed payload.
3. EvidenceRef/envelope separates source kind OBSERVED/RECONSTRUCTED/SYNTHETIC/COUNTERFACTUAL, parent hashes, source schema/commit/artifact/locator and actual-byte checksum. Declare which fields are supported in this bounded version; refuse unsupported execution/native capability rather than populate invented defaults. Source/hash annotations are supplied claims with verification scope, not proof that RPC/backend/round was independently validated. Require derivation/parent refs for derived/counterfactual fields. No API automatically promotes derived or synthetic children to OBSERVED. Synthetic fixture IDs are visibly synthetic.
4. Hash domains: raw artifact SHA256, optional decoded SHA256, canonical deterministic content SHA256 and Git blob SHA1 are distinct typed names. Do not normalize file LF/CRLF/gzip before checking raw checksums. Canonical derived payload is schema-versioned, sorted string-key compact JSON UTF-8, `ensure_ascii=False`, no trailing LF, no floats/NaN/Infinity or binary values; integers serialized by schema as normalized base10 strings, no leading zero/-0. Reject noncanonical numeric strings at strict decode; convenience construction from valid exact integers may emit canonical strings. Ordinary textual fields are not reinterpreted as integers. Preserve Unicode scalar sequences without normalization; reject invalid surrogate encodings and non-string dictionary keys. Booleans only in explicitly boolean fields, never accepted in integer fields. Duplicate JSON keys rejected before dict construction. Tuple/list may share array serialization only where the schema explicitly defines an ordered vector; no set-order dependence. Acquisition metadata excluded from deterministic payload only by explicit field schema; economic/block/available timestamps stay in payload. Document included/excluded fields and schema version (`defistress-v2-contracts/0.1` as first proposed implementation version).
5. Pure same-block/available-time join guards compare chain/number/hash and applicable effective/available timestamp against the supplied as-of context. Reorg/canonicality assertion needs an evidence ref and its observation time; it is not timeless truth. Missing source/profile or unsupported native round yields reasoned unavailable value; it is not round0. No price, HF, swap or liquidation computation in this package. Type-only records for future state references are acceptable; no TransitionProposal executor or capability escalation.
