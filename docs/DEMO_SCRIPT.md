# Professor Demo Procedure

Target duration is 5–7 minutes. Capture a real Mainnet snapshot before the presentation and keep the immutable cached copy. If credentials are unavailable, present fixture mode only after explicitly identifying it as synthetic.

## 0:00 to 0:45 Overview

Open `/overview`. Read the mode badge first. For a real/cached snapshot say: “This is Ethereum Mainnet block B,” then show block hash, timestamp, Aave market, WETH/USDC prices, sampled debt, borrower count, and source health. Do not say this for `FIXTURE`.

## 0:45 to 1:30 Positions

Open `/positions`. Show the HF histogram and filter to 1.00–1.20. Explain pseudonyms, Top-N/lookback coverage, failed reads, and the distinction between Aave aggregate HF and internal cross-check.

## 1:30 to 2:10 Liquidity

Open `/liquidity`. Show all resolved fee tiers, the transparent ±2% depth selection, `sqrtPriceX96`, tick, active liquidity, and executable depth at ±1%, ±2%, and ±5%. If `TICK_DATA_INCOMPLETE` is visible, state that large-trade fidelity still requires a Quoter or fork quote.

## 2:10 to 3:00 Scenario

Open `/scenarios`. Select ETH shock −20%, liquidity haircut 40%, gas 2×, arbitrage capacity 50%, seed 20260914. Explain that overrides are counterfactual and never mutate the snapshot.

## 3:00 to 4:10 Simulator

Run deterministic mode from `/scenarios`; the application opens `/results/[runId]`. Walk through Wave 1 eligibility, liquidator profit/capacity, collateral seizure, forced WETH sale, V3 price impact, arbitrage response, and any Wave 2. If no real-data cascade occurs, state “No endogenous cascade detected” and use Find Cascade Threshold rather than inventing a result.

## 4:10 to 5:00 Results and compare

Open the run result. Read liquidation-at-risk, total liquidated debt, amplification, max price impact, bad debt, cascade depth, and recovery. Compare baseline with low-liquidity or no-arbitrage using the same snapshot.

## 5:00 to 5:45 Provenance and validation

Open `/provenance`, show the block, address-book commit, contract addresses, formulas, seed, and model version. Open `/validation` and show PASS/FAIL/NOT RUN honestly. Explain the internal HF tolerance and any data-quality flags.

## 5:45 to 6:30 Reproducibility close

Download the experiment ZIP. Show `manifest.json`, `events.csv`, and charts. Close with: “This result was generated by a pinned snapshot, scenario, model version, and seed; the manifest makes the experiment reproducible.” Use the stronger “not synthetic” statement only for `REAL_MAINNET` or `CACHED_MAINNET`.
