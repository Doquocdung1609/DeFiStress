# Counterfactual Experiments

`COUNTERFACTUAL_STRESS` starts from the same cutoff state and can change withdrawal shock, liquidity impact/depth, arbitrage capacity, reserve capacity/timing, reaction delay, redemption friction, confidence sensitivity, and price impact.

Outputs display historical replay beside the altered simulation and carry `COUNTERFACTUAL — not historical reality`. Counterfactual values are not inserted into the ground-truth dataset.
